# 2026-11-01

## 博客打赏区改为"微信赞赏"（Hexo + cards 主题）

- 站点：Hexo 7.3.0，`_config.yml` 中 `theme: cards`（`themes/butterfly` 未启用）。
- 主要改动 1：`themes/cards/layout/_meta/copyright.ejs`
  - 移除原 bilibili 发电 / Alipay 两个 `.reward-bottom` 按钮。
  - 改为单个 `.reward-wechat` 按钮，点击调用 `openWechatReward()`，弹出微信赞赏二维码
    （图 `https://cdn.luogu.com.cn/upload/image_hosting/lk5s3h7d.webp`）。
  - 弹窗结构：`.wechat-reward-modal > .wechat-reward-mask + .wechat-reward-box > img + .wechat-reward-close`，
    支持点遮罩关闭 / Esc 关闭 / 右上角 × 关闭。
  - 关键实现：打开时若 modal 的 parentNode 不是 body，先 `document.body.appendChild(modal)`，
    避免祖先元素（transform/filter 等）成为 fixed 定位的包含块导致弹窗偏移或超宽。
- 主要改动 2：`themes/cards/source/css/style_light.css`（在 `.reward-bottom:hover` 之后新增「微信赞赏」段）
  - `.post_reward.active` 上下留白、hover 透明；`.reward-container` 高度改 50px / padding 0。
  - `.reward-wechat`：全宽胶囊、`#07c160` 微信绿、白字、hover `#06ad56`。
  - `.wechat-reward-modal`：fixed 全屏、`z-index: 9999`、半透明遮罩 + `backdrop-filter: blur(3px)`。
  - `.wechat-reward-box`：白卡、`max-width: min(88vw, 420px)`、`max-height: 88vh`、圆角 16px。
  - `.wechat-reward-box img`：`min-width: 0; flex: 0 1 auto; max-width: 100% !important`（防 flex 子项按图片原宽溢出）。
- 验证方式：`npx hexo generate` 后用 `python -m http.server` 起 public 目录，
  Chrome headless（`--headless=new --screenshot --window-size=...`）截图；长页面需用超高窗口 + PIL 裁剪，
  因为 headless 截图始终从文档顶部开始，`scrollTo/scrollIntoView` 不生效。
- 注意：`temp.css`（项目根）与 `themes/butterfly` 里的同名 reward 样式均未被引用，未改动。
- 样式修订（用户要求「按博客原有风格，不用圆角、不高饱和、用原有配色」）：
  - 按钮改为 `.post_reward` 原底色 `#d9d9d9` + 深色字 `#303030`，hover `#cfcfcf`，`border-radius: 0`；
    不再用微信绿 `#07c160`，无缩放/位移动画。
  - 弹窗卡片直角 + `1px solid rgba(0,0,0,0.22)` 描边（与 `.post-entry::after` 分隔线同色）、无阴影；
  - 关闭按钮 30px 直角描边方块，hover `#f0f0f0`；遮罩 `rgba(0,0,0,0.55)` 且去掉 `backdrop-filter`；
  - 入场动画只保留透明度淡入。
  - 再修订：按钮默认 `background-color: transparent`（只剩文字），hover 才显示 `#d9d9d9` 底；仍是直角、深灰字。
  - 该站点整体视觉约定：`border-radius: 0` 为主、灰阶中性色、链接色 `rgba(104,104,104,0.695)`。
